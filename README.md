# OHLA – interaktywna oś czasu zasobów (ressurs)

Otwórz `index.html` w przeglądarce (jeden plik, bez instalacji).

- Oś czasu 08.2024 – 12.2026 z rolami pogrupowanymi wg zasobów (Ressurs 1/2/3 + usługi wspólne).
- Przeciągnij suwak lub kliknij na osi, aby zobaczyć stan na wybraną datę (liczba zasobów, role, zadania).
- Kliknij pasek roli, aby zobaczyć listę obowiązków; kliknij zdarzenie, aby przejść do daty.
- Porównanie Okresu 1 i Okresu 2, przełącznik języka NO/EN (norweski / angielski), tryb jasny/ciemny.

Kolory i czcionki pochodzą z identyfikacji NORMA Geosystems (norma-gs.no: antracyt #383E42, żółty #F4BB29, Space Grotesk / Inter / JetBrains Mono) i są zdefiniowane w bloku `:root` na początku `index.html`. Logo w katalogu `assets/`.
Dane (role, daty, obowiązki) znajdują się w sekcji `DATA` w skrypcie.
